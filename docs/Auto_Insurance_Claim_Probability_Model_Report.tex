\section{Executive Summary}

This project estimates the probability that an auto insurance policy produces a claim. The modeling path deliberately starts with a single-variable linear regression baseline, then expands to a multivariate linear probability model, and finally uses logistic regression as a binomial GLM-style model for binary claim occurrence.

The R implementation achieved a holdout ROC-AUC of 0.606 and a top-decile lift of 1.68x. This indicates modest but useful risk segmentation: the highest predicted-risk decile has meaningfully higher observed claim frequency than the overall portfolio. The result is presented as an actuarial analytics finding, not as an overclaimed high-accuracy machine learning result.

\section{Business Question}

Can policy, driver, regional, and vehicle characteristics identify policies with above-average claim probability? This is a P\&C frequency modeling problem because the response variable is whether a claim occurred, not the dollar amount of loss.

\section{Model Design}

\subsection{1. Simple Linear Regression Baseline}

The first model uses \texttt{subscription\_length} alone to predict the binary claim indicator. It is useful as a transparent benchmark, but it treats a binary outcome as continuous and can be inappropriate as a final probability model.

\subsection{2. Multiple Linear Probability Model}

The second model keeps a linear structure but adds policy, customer, region, and vehicle variables. It tests whether broader underwriting information improves risk segmentation, while still allowing impossible probability predictions below 0 or above 1.

\subsection{3. Logistic Regression}

The final model uses a binomial logistic link:

\[
\log\left(\frac{p}{1-p}\right) = \beta_0 + \beta_1x_1 + \cdots + \beta_kx_k,
\]

where \(p\) is the probability that a policy has a claim. This constrains predictions to valid probabilities and connects naturally to the GLM framework commonly used in actuarial pricing and claim occurrence modeling.

\section{Evaluation Approach}

Only about 6.4\% of policies have claims, so accuracy alone can be misleading. A model that predicts ``no claim'' for almost all policies may appear accurate while failing to identify claim-prone risks. This project therefore emphasizes ranking, probability quality, and business segmentation.

\section{Interpretation}

The logistic regression model improves high-risk segmentation relative to the simple baseline. The top-decile lift increases from 1.42x to 1.68x in the R workflow. This means the highest predicted-risk policies show approximately 68\% higher observed claim frequency than the overall test portfolio.

The ROC-AUC remains modest, which is an important professional conclusion rather than a weakness to hide. The available rating variables provide some separation but not a highly predictive model. A production actuarial workflow would benefit from exposure measures, coverage details, prior claims, loss amounts, and stronger territorial or behavioral risk variables.

\section{Public Repository Positioning}

This project demonstrates practical insurance analytics skills:

\begin{itemize}
  \item clean data handling and train/test validation;
  \item baseline modeling with simple linear regression;
  \item GLM-style claim occurrence modeling with R \texttt{glm(..., family = binomial)};
  \item imbalanced classification evaluation using ROC-AUC, Brier score, precision, recall, and lift;
  \item actuarial interpretation of model limitations and next steps.
\end{itemize}

\section{Possible Extensions}

Future work could add regularized GLMs, cross-validation, territorial credibility adjustments, claim frequency models using Poisson GLMs, and severity modeling if claim amount data becomes available.
